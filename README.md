## 1. Описание проекта
«Чудо обувь» — настольное приложение для автоматизации работы обувного магазина. Система предназначена для просмотра каталога обуви, оформления заказов, учёта товарных остатков и управления заказами.

**Основные возможности:**
* просмотр каталога обуви с подсветкой позиций с низким остатком;
* поиск товаров по наименованию и описанию;
* фильтрация по категориям и сортировка по цене;
* просмотр детальной информации о товаре;
* добавление товаров в корзину и оформление заказов;
* просмотр и обработка заказов;
* автоматическое обновление остатков товаров после оформления заказа;
* применение скидки 25% к товарам, по которым не было заказов в предыдущем календарном месяце.

**Технологии:**
* Язык программирования: **C#**;
* Пользовательский интерфейс: **WPF**;
* Платформа: **.NET Framework 4.7.2**;
* База данных: **Microsoft SQL Server**;
* Работа с данными: **Entity Framework 6**.

## 3. Установка и запуск
Для запуска приложения необходимо:
1. Установить **Visual Studio** с поддержкой WPF и .NET Framework 4.7.2.
2. Установить **Microsoft SQL Server**.
3. Выполнить SQL-скрипт `ShoesAppDB.sql`, расположенный в папке проекта, для создания базы данных `ShoesShop`.
4. Открыть файл `ShoesApp.sln` в Visual Studio.
5. В файлах `App.config` и `ShoesApp.exe.config` указать имя своего экземпляра SQL Server в строке подключения.
6. Собрать проект и запустить приложение клавишей `F5`.

## 4. Использование
После запуска приложение открывает каталог обуви. Неавторизованный пользователь может только просматривать каталог товаров. Для оформления заказов и доступа к дополнительным возможностям требуется авторизация по логину без пароля.

Система поддерживает ролевую модель доступа:
- **Авторизованный пользователь** — может просматривать каталог, выполнять поиск, фильтрацию и сортировку по каталогу, добавлять товары в корзину, оформлять заказы и просматривать историю своих заказов.
- **Менеджер** — наследует возможности авторизованного пользователя, а также может просматривать все заказы, оформлять и удалять их.
- **Администратор** — имеет полный доступ к системе, включая редактирование заказов.

Интерфейс автоматически подстраивается под текущую роль пользователя. Недоступные действия скрываются.

**Описание основных компонентов:**
- `pages/` — содержит XAML-страницы приложения и их программную логику.

- `OrderPositionClass.cs` — добавочный класс для работы с позициями заказа.
- `UsersClass.cs` — добавочный класс для работы с данными пользователей.
- `App.xaml` / `App.xaml.cs` — точка входа в приложение и глобальные настройки.
- `MainWindow.xaml` / `MainWindow.xaml.cs` — главное окно приложения.

## 6. База данных
Приложение использует реляционную базу данных `ShoesShop`. Взаимодействие с ней осуществляется с помощью Entity Framework.

**Ключевые сущности:**
- `Users` и `Roles` — пользователи системы и их роли;
- `Products` — информация о моделях обуви;
- `Categories` и `Subcategories` — справочники категорий и подкатегорий товаров.
- `Productions` — справочник производителей.
- `Sizes` — справочник доступных размеров обуви;
- `Sizes_Of_Product` — учёт остатков товаров по размерам;
- `Materials` — справочник материалов.
- `ShoesAreas` — области применения материала.
- `Structure` — состав модели обуви.
- `Orders` — оформленные заказы;
- `Order_Positions` — товарные позиции в заказах.
